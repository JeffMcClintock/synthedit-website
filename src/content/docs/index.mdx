  var el = document.querySelector('.se-hero-audio');
  if (!el || !window.Audio) return;
  var snd = new Audio();
  snd.preload = 'none';
  snd.src = snd.canPlayType('audio/flac') ? el.getAttribute('data-flac') : el.getAttribute('data-mp3');
  var fill = el.querySelector('.se-hero-audio-progress i');
  el.setAttribute('role', 'button');
  el.setAttribute('aria-label', 'Play a 36 second StateVar Filter audio demo');
  el.addEventListener('click', function(e){
    e.preventDefault();
    if (snd.paused) { snd.play(); el.classList.add('is-playing'); }
    else { snd.pause(); el.classList.remove('is-playing'); }
  });
  snd.addEventListener('timeupdate', function(){
    if (snd.duration) fill.style.width = (snd.currentTime / snd.duration * 100) + '%';
  });
  snd.addEventListener('ended', function(){
    el.classList.remove('is-playing');
    fill.style.width = '0%';
  });
})();`}</script>

<section class="se-section" style="padding-top: 0">
  <div class="se-section-head">
    <div class="se-eyebrow">Known limits</div>
    <h2 class="se-section-title">What it doesn't do yet</h2>
    <p class="se-section-sub">Things I'd rather you heard from me now than discovered on day three.</p>
  </div>

  <ul class="se-limits">
    <li class="se-limit">
      <span class="se-limit-tag">MIDI</span>
      <p>MIDI processing can be awkward. The VST3 format's MIDI support is limited, and that constrains MIDI-effect-style plugins more than I'd like.</p>
    </li>
    <li class="se-limit">
      <span class="se-limit-tag">Standalone</span>
      <p>Exporting a standalone application isn't supported yet. Today the built-in export targets are VST3 and Audio Unit.</p>
    </li>
    <li class="se-limit">
      <span class="se-limit-tag">CLAP</span>
      <p>CLAP support isn't ready yet.</p>
    </li>
    <li class="se-limit">
      <span class="se-limit-tag">Linux</span>
      <p>The Linux port is an experimental preview, with PipeWire audio. The editor needs a Wayland session — there's no X11 build of it. Export works, but it's brand new: the plugins carry both an X11 and a Wayland path in one binary and pick whichever the host offers, so test yours before you ship it. It's free while it's in preview.</p>
    </li>
  </ul>
</section>
